Install and requirements

On your machine

npx toyon ~/projects/app

Local by default, with the agent you already use: Claude Code, Codex or OpenCode.

What you need

On your own server

npx toyon deploy fly up my-toyon

Runs on with your laptop closed, on Fly or a box behind Tailscale. Your code and keys never pass through a Toyon server.

How to set it up

Ask, and watch it change

Say what you want, or point at it on the page. The app updates as the agent works; steer it, or fix the small thing yourself.

  • Know where every chat stands

    The dot beside each chat says whether its app is up or it is waiting on you; the counts say what it changed.

  • From your phone

    Pair your phone from the top bar. Start a chat from it, steer one that is running, or check the copy on a real phone screen.
